ROI Influencer Importer – Cursor Rules
Project Scope

This is an internal WordPress admin-only plugin for ROI-NJ.

The plugin:

Imports a CSV file

Creates WordPress posts

Assigns categories

Assigns TagDiv Cloud templates

Sets publish dates with spacing

Assigns featured images based on filename

Supports batch publishing

Displays import reports and warnings

The plugin MUST NOT:

Modify theme files

Modify frontend queries

Override global WordPress behavior

Hook into frontend rendering

Add REST endpoints

Add AJAX unless explicitly required

Introduce external libraries or frameworks

Add unnecessary abstraction layers

Keep the implementation simple and procedural unless complexity requires structure.

Development Constraints

Admin-only functionality

No frontend rendering logic

No database schema changes

No custom tables

Use standard WordPress APIs only

Use wp_insert_post and wp_update_post

Use native media library queries for image matching

Store batch tracking in post meta only

Keep everything inside the plugin folder

Avoid global state where possible

Architecture Guidelines

Single main plugin bootstrap file: roi-influencer-importer.php

Additional files may be placed inside /admin and /includes

Do not over-structure prematurely

Build incrementally

Each feature should be testable independently

Image Matching Rules

Expected filename format:
{LastName}, {FirstName} - {TitleSuffix}.png

Match by exact filename

If not found:

Still create post

Log warning

Display warning after import

No fuzzy matching or fallback logic unless explicitly requested.

Sorting Rules

Sort strictly by lastname column

Ignore suffixes

Use publish date spacing system

Do not modify frontend sort logic

Publishing Rules

Default status = draft

Preserve post_date when publishing batch

Never allow bulk publish to reset timestamps

Use controlled batch publishing via plugin interface

Code Quality Rules

No anonymous complex closures

No unnecessary classes unless needed

No dependency injection

No external packages

No Composer

No build tools

Keep it WordPress-native

Safety

The plugin must:

Fail safely

Never break the site

Never alter global queries

Never modify theme behavior

All errors must be contained to admin screens.
